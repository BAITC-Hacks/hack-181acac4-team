## Контракт продукта

- Карточка задачи содержит: название, контекст, потребность, пользователей, данные и материалы, ограничения, ожидаемый результат, критерии успеха, контакт и формат взаимодействия. Сведения, предложенные AI, редактирует и подтверждает человек до публикации.
- Конструктор принимает свободное описание и **всегда** задаёт минимум три уместных вопроса: о пробелах в кратком описании или для уточнения подробного. Вопросы опираются на конкретный текст бизнеса; фиксированный одинаковый список для всех задач не подходит. После ответов AI собирает редактируемую карточку. Неизвестные сведения остаются пустыми, AI не выдумывает факты. Если ответов недостаточно, бизнес может ответить на следующий вопрос или заполнить поле вручную.
- Основной AI-провайдер — OpenAI. Ключ хранится только в переменной окружения `OPENAI_API_KEY`; модель настраивается через `OPENAI_MODEL`. При ошибке API конструктор показывает понятную ошибку и даёт повторить запрос. Локальная заглушка допустима для демо, если внешний API недоступен; зафиксируй её промпт, формат входа/выхода и обработку некорректного ответа. Второй AI-провайдер не входит в обязательный сценарий.
- Рейтинг от 0 до 100 начисляется только за заполненные и подтверждённые сведения: контекст и потребность — 20, данные — 20, результат — 15, критерии успеха — 15, ограничения — 10, пользователи — 10, связь с бизнесом — 10. Показывай разбивку и недостающие сведения. Пересчитывай после подтверждённого редактирования.
- Уровни готовности: 0–39 — черновик, 40–69 — рабочая, 70–89 — готовая, 90–100 — приоритетная. Низкий рейтинг не скрывает опубликованную задачу и не блокирует отклик.
- Все опубликованные задачи доступны всем командам. Каталог сортируется по рейтингу и фильтруется по теме и уровню готовности. Рекомендации могут быть только дополнением к общему каталогу.
- Любая команда может подать любое число предложений с идеей решения, планом, сроком и ссылкой на прототип. Бизнес вручную выбирает одну, несколько или ни одной команды и может отклонять предложения. Автоматическое назначение запрещено.
- Используй синтетические данные: минимум 5 черновиков, 5 карточек, 5 профилей команд и 5 предложений. Не коммить секреты, токены и реальные персональные данные.

## Стек и обмен данными

- Frontend: React, TypeScript, Vite. Backend: Python, FastAPI, Pydantic и SQLAlchemy 2. База: PostgreSQL. Локальный запуск: Docker Compose. Python API отдаёт JSON; имена полей в JSON — `snake_case`, идентификаторы — строки UUID.
- `TaskDraft`: `id`, `business_id`, `raw_description`, извлечённые `known_fields`, список `questions` (`id`, `text`, `field_keys`), `answers` (`question_id`, `text`), `status` (`collecting` или `card_created`). Создание черновика возвращает минимум три вопроса даже при подробном вводе.
- `TaskCard`: `id`, `draft_id`, `business_id`, `topic`, `title`, `context`, `need`, `users`, `data`, `constraints`, `expected_result`, `success_criteria`, `contact`, `interaction_format`, `status` (`editing`, `confirmed`, `published`). Неизвестные текстовые поля — пустые строки; AI не подставляет предположения. Публикация разрешена только после подтверждения бизнесом.
- `ScoreBreakdown`: `total` (0–100), `level` (`draft`, `workable`, `ready`, `priority`), `criteria` с полученными и максимальными баллами по семи категориям, `missing_fields`. Уровень готовности зависит только от баллов и не совпадает со статусом публикации. Официальный рейтинг относится к подтверждённой карточке и пересчитывается после подтверждённой правки.
- `TeamProfile`: `id`, `name`, `skills`, `interests`, `contact`. `Proposal`: `id`, `task_id`, `team_id`, `idea`, `plan`, `timeline`, `prototype_url`, `status` (`submitted`, `accepted`, `rejected`). Принятие одного предложения не меняет статусы других: бизнес может выбрать несколько команд.
- Основной API: `POST /api/drafts` (описание → черновик и вопросы), `POST /api/drafts/{id}/answers` (ответы → карточка), `PATCH /api/cards/{id}` (правка), `POST /api/cards/{id}/confirm` (подтверждение и рейтинг), `POST /api/cards/{id}/publish`, `GET /api/tasks` (только опубликованные, сортировка по рейтингу и фильтры), `GET /api/tasks/{id}`, `POST /api/tasks/{id}/proposals`, `GET /api/tasks/{id}/proposals`, `POST /api/proposals/{id}/decision` (только решение бизнеса). Общие схемы и маршруты меняет Anuar.
